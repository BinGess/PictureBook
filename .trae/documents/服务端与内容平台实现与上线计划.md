## 目标
- 为现有 iPad 绘本客户端提供稳定的服务端与内容操作平台（后台），涵盖数据存储、接口设计、基础推荐、文件存储与部署上线。
- 与客户端当前数据结构完全对齐，支持编辑推荐区、正常推荐流分页、沉浸式阅读页的数据拉取与读完相关推荐。

## 技术栈
- 后端：Go 1.21 + Gin（HTTP 框架）
- 数据库：PostgreSQL（托管或自建），迁移工具：golang-migrate
- ORM/DB：sqlc 或 sqlx（更轻）、可选 GORM（上手快）
- 认证：JWT（HS256），后台管理使用会话（Cookie + CSRF）
- 存储：S3 兼容（AWS S3/Cloudflare R2/MinIO），CDN 加速（CloudFront/Cloudflare）
- 日志与监控：zerolog、/healthz、pprof（可选）
- 前端后台：Gin + html/template（表单为主，少量 HTMX/Alpine.js 增强）

## 数据模型
- Book：`id(uuid)`, `title`, `cover_url`, `age_min`, `age_max`, `tags(jsonb)`, `popularity_score`, `theme_keywords(jsonb)`, `is_editor_pick`, `status(draft|published)`, `created_at`, `updated_at`
- Page：`id(uuid)`, `book_id`, `index`, `image_url`, `duration_hint?`, `created_at`
- Admin：`id(uuid)`, `email`, `password_hash`, `created_at`
- 约束：编辑推荐 `is_editor_pick=true` 的数量≤5（在应用层与 DB 层双重校验）

## API 设计（v1）
- 公共接口（客户端使用）
  - `GET /v1/editor-picks` → 返回≤5本编辑推荐（已发布 `status=published`）
  - `GET /v1/books` → 查询参数：`age`, `sort=popular|age_fit|combined`, `page`, `page_size`；返回：`items[]` 与 `paging{page,page_size,has_more,total?}`
  - `GET /v1/books/{id}` → 书籍详情含 `pages[]`
  - `GET /v1/books/{id}/recommendations?age=&limit=5` → 读完相关推荐（热门兜底）
  - `GET /v1/assets/{name}` → 静态资源代理（如采用本地/私有路径时）
- 后台接口（需要 JWT）
  - 认证：`POST /v1/admin/login`（返回 JWT/cookie），`POST /v1/admin/logout`
  - 书籍：`GET /v1/admin/books`，`POST /v1/admin/books`，`PUT /v1/admin/books/{id}`，`DELETE /v1/admin/books/{id}`
  - 页面：`GET /v1/admin/books/{id}/pages`，`POST` 批量创建/上传，`PUT` 单页更新，`DELETE` 单页删除
  - 上传：`POST /v1/admin/upload`（返回 `file_url`/`key`），可选直传策略（STS/预签名 URL）

## 推荐逻辑
- 评分：`score = 0.5*popularity + 0.3*ageFit + 0.2*themeSimilarity`
  - `ageFit`：按用户年龄与 `age_min/age_max` 计算匹配度
  - `themeSimilarity`：`tags + theme_keywords` 的 Jaccard 相似度（初期）
- 读完推荐：按主题相似排序，数量不足用热门度兜底；排除当前书籍

## 后台管理（MVP）
- 登录页：邮箱/密码（bcrypt/argon2id），错误提示与锁定策略（基础）
- 书籍列表：搜索/筛选（状态/编辑推荐），分页
- 创建/编辑书籍：标题、适龄、标签、主题、热门度、编辑推荐开关；保存校验（编辑推荐≤5）
- 页面管理：批量上传图片、设置页序index、预览；拖拽排序（可后续）
- 发布流：`draft → published`，未发布不出现在公共接口

## 安全与合规
- 公共接口只读，速率限制（IP/Token级）
- CORS：仅允许 iPad 客户端域名；后台页面同域
- 管理登录：强密码策略、CSRF 防护（表单携带 token）、密码哈希（argon2id/bcrypt）
- 上传：仅白名单 MIME 类型（图像），大小限制；病毒扫描（可选）

## 项目结构
- `cmd/server/main.go`（启动入口）
- `internal/config`（读取环境变量）
- `internal/db`（连接、迁移）
- `internal/models`（Book/Page/Admin）
- `internal/repository`（SQL 查询/持久化）
- `internal/services`（推荐、上传、业务逻辑）
- `internal/handlers`（HTTP 路由/JSON 序列化）
- `internal/middleware`（认证、日志、CORS、限流）
- `web/admin`（模板与静态资源）

## 与客户端的对接改造
- `ContentService`：新增远端拉取逻辑，优先使用 `BASE_URL` 接口；失败时 fallback 本地 JSON
- 主页：使用 `GET /v1/editor-picks` 与 `GET /v1/books?page=...` 替代本地排序
- 阅读页：读完调用 `GET /v1/books/{id}/recommendations` 获取相关推荐
- 统一数据结构：服务端 JSON 字段与现有 `Book`/`PageModel` 对齐

## 部署策略
- 容器化：`Dockerfile`（Go 构建），`docker-compose`（本地 Postgres+MinIO）
- 云平台：Render/Fly.io/Railway（任选其一，建议 Render 简化）
  - 创建 Web Service（Go），创建托管 Postgres
  - 环境变量：`DATABASE_URL`, `JWT_SECRET`, `S3_BUCKET`, `S3_ENDPOINT`, `S3_ACCESS_KEY`, `S3_SECRET_KEY`, `CORS_ALLOWED_ORIGINS`
  - 配置健康检查 `/healthz`，自动重启
- 存储与 CDN：Cloudflare R2 + 公网访问域名/自定义 CDN，上传返回公网 URL 给客户端使用
- 域名与证书：平台自动 HTTPS，或自定义域名/证书（Cloudflare）

## 测试与验收
- 单元测试：推荐打分、编辑推荐数量校验、分页与排序
- 集成测试：接口端到端（httptest + 本地 Postgres）
- 负载与稳定性：基本并发/速率限制，观察日志与资源占用
- 验收：客户端切换到服务端接口后功能一致，读完推荐准确

## 里程碑与交付
- M1：数据库建模与迁移、工程脚手架、公共接口的 `GET /v1/books` 与 `GET /v1/editor-picks`
- M2：`GET /v1/books/{id}`、`GET /v1/books/{id}/recommendations`、推荐服务
- M3：后台管理登录与书籍/页面 CRUD、上传与发布流
- M4：容器化与部署上线、CDN 接入、客户端切换并完成联调

## 风险与应对
- 图片资源体积：采用 WebP/HEIF 与 CDN，限制上传大小
- 编辑推荐上限：双重校验与后台表单提示
- 弱网场景：客户端保留本地 JSON fallback
